Access Instructions

Reach CaseFlow without a public domain — Tailscale, SSH tunnel, or private LAN.

Tailscale

If Tailscale is installed and connected:

http://100.68.147.74:3000

or MagicDNS:

http://caseflow.tail18069f.ts.net:3000

Requires: Tailscale on the same tailnet

SSH tunnel

No Tailscale client needed on your laptop:

  1. Download tunnel.sh
  2. chmod +x tunnel.sh && ./tunnel.sh
  3. Open http://localhost:3000

Requires: Your SSH public key added by an admin

tunnel.sh

Private network

Same LAN/VPN and allowlisted CIDR only:

http://[server-ip]:3000

Requires: Firewall + ALLOWED_CIDRS

Need help?

  • Email: admin@caseflow.local
  • Admins: Users → Invite User / SSH Access
  • Full guide: docs/ACCESS.md in the repo
